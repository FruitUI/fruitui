The small things, considered

Good interfaces start here.

Native HTML. Shared styles. Just enough behavior.

Foundation · 0.1

Buttons

A clear primary action, with quiet supporting controls.

<button class="f-button f-button--primary">
  Continue
</button>

Text fields

Familiar controls, with explicit labels and helpful context.

<label class="f-field">
  <span class="f-label">Your name</span>
  <input class="f-input">
</label>

Selection controls

Real inputs. Keyboard accessible, without JavaScript.

<label class="f-switch">
  <input type="checkbox" role="switch">
  <span>Show message previews</span>
</label>

Segmented controls

A small set of related choices, powered by native radios.

Preview position
<div class="f-segmented">
  <label><input type="radio" name="view">
    <span>Right</span></label>
</div>

Disclosure

Let people reveal the details when they need them.

What makes FruitUI CSS first?

Layout, appearance, selection controls, focus states, and this disclosure all work with native HTML and CSS. Add Alpine or Livewire when your interface needs state or server actions.

<details class="f-disclosure">
  <summary>More details</summary>
  <p>The details, when you need them.</p>
</details>

Dialogs

Native focus management and Escape dismissal. A little Alpine to open.

A moment of focus.

Good dialogs ask for one thing at a time. This one just wanted to say hello.

<div x-data="fruitDialog">
  <button @click="open">Open</button>
  <dialog class="f-dialog" x-ref="dialog">
    …
  </dialog>
</div>

Fits the way you build.

Use the CSS on its own, add Alpine for local behavior, or let Laravel and Livewire handle your data.

HTML & CSS

import 'fruitui/css';

<main class="fruit-ui">
  <button class="f-button">
    Hello, world
  </button>
</main>

Alpine.js

import Alpine from 'alpinejs';
import fruitUI from 'fruitui/alpine';

fruitUI(Alpine);
Alpine.start();

Laravel & Livewire

<x-fruit::button
  wire:click="save"
  wire:loading.attr="disabled"
  variant="primary">
  Save changes
</x-fruit::button>

<x-fruit::switch
  wire:model="previews">
  Show previews
</x-fruit::switch>
