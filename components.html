Example compositions

Charts, breadcrumbs, customer tabs, full Support inspectors, and Chat message arrangements remain example compositions. Their frames, panes, composers, facts, floating disclosures, and native tables now use the cataloged shared styles. Application data and navigation stay local. See the Admin, Support, and Chat examples for those arrangements.

Fits the way you build.

Use the CSS on its own, add Alpine for local behavior, or let Laravel and Livewire handle your data.
